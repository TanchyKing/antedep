All 30 cells match the doc to displayed precision.

### A.2 Two rows are NOT regenerable from the current pipeline

`23_marginal_moments_bolus.R` computes moments for empirical, both INAD, NB GLM,
NB GLMM, tscount, and CGFM via `cgfm_bolus_published_specs()` -- and that spec
(in `common/cgfm_marginal.R`) holds only **independent (phi=0.49)** and
**shared (phi=0.24)**. So the current pipeline produces:

- **no Poisson GLM moment row**, and
- **no CGFM time-varying row** (no time-varying spec exists in code).

The committed `relative_error_*_by_time.csv` and `marginal_moments_bolus.csv`
therefore have neither column. The doc's two missing rows
(Poisson `9.95/59.70/64.84/5.96/78.52`; time-varying `8.96/42.26/29.70/6.88/21.08`)
are **carried over from last week's summary**, not regenerable today.

### A.3 ...but they match last week's committed summary verbatim

`inad-validation-summary.md` Section 6.1 contains the full 8-row MARD table.
Every cell -- including the Poisson and CGFM time-varying rows -- matches the
new doc exactly (40/40). Last week's summary was generated by an earlier
pipeline version that *did* compute Poisson and time-varying moments (its
Section 6.5 by-time tables still carry a Poisson column; the current CSVs do
not). So the provenance is sound: the new table faithfully reproduces an
already-delivered, internally consistent table. It is simply not
self-reproducible from the current repo state.

**Implication (non-blocking):** if the advisor asks to *rerun and confirm*,
the Poisson and time-varying rows will not regenerate. To make the new doc
self-contained one would restore the Poisson moment model and add a
time-varying spec (phi from Henderson-Shimakura) to `cgfm_bolus_published_specs()`.
For a summary that explicitly cites last week's table, citing is acceptable.

### A.4 Prose claims are true and robust

"INAD class gives the best MARD ... unconstrained INAD best for G1 mean, G2
mean, G2 variance; constrained-alpha INAD best for G1 variance." Verified
against the table:

- G1 mean: U-INAD 5.92 (next 8.35) -- best.
- G1 var: C-alpha 26.74 (next CGFM shared 29.01) -- best.
- G2 mean: U-INAD 5.83 (next Poisson 5.96, CGFM shared 6.01) -- best.
- G2 var: U-INAD 19.72 (next CGFM ind 20.75) -- best.
- (G1 var excl.: C-alpha 15.65 also best; not separately claimed.)

INAD is strictly best in **every** column. Crucially, in each column INAD
beats the best *verified* competitor, so the headline does **not** depend on
the two non-reproducible rows. The only place an unverified row is the runner-up
is G2 mean (Poisson 5.96 vs U-INAD 5.83) -- still behind, and behind the
verified CGFM shared 6.01 as well.

The NB-GLM/CGFM-independent equivalence note (lines 20-27) is accurate and
well-qualified: same NB predictive family under matched linear predictor and
dispersion; the small gaps come from two separate parameter fits
(local `glm.nb` vs published H-S phi=0.49). Consistent with the near-equal
cells (G1 var 42.36 vs 42.44; G2 var 21.01 vs 20.75).
